# Быстрая выдача и возврат байков — дизайн

Дата: 2026-10-19. Статус: одобрено юзером («делай»).

## Цель

Стойка за 30–60 секунд: клиент пришёл → выбрал байк → подписал → дал залог (2 млн донг ИЛИ паспорт) → уехал.
Одна транзакция на сервере, дашборд наполняется сам, руками ничего не заводить.
Хозяину с главного экрана видно: кто на каком байке сейчас и кто сдаёт в ближайшие дни.

## Решения

- Залог: кэш (по умолчанию 2 000 000 VND, редактируется) или паспорт (document custody). Суммы/ставки подставляются, правятся руками.
- Выдача кэшем без паспорта разрешена (осознанно отступаем от ready-правила «нужен документ»: квик-эндпоинт сам делает всю цепочку).
- Ставка за день: поле визарда, по умолчанию 150 000 VND, запоминается в localStorage.
- Фото: опционально, грузятся после транзакции на сущность handover / return_inspection.
- Продление: +1/+3 дня к item и к арендной обязанности (amount пересчитывается rate × дней).

## API

- `POST /api/rentals/quick` — одна транзакция: клиент (существующий или новый), agreement(active), item(active), handover, bike→rented, obligation rent, deposit (+custody для паспорта). Возвращает `{clientId, agreementId, itemId, handoverId, depositId, documentCustodyId}`.
- `POST /api/rentals/items/:id/extend` `{days}` — продлить активную позицию; item.endDate += days, agreement.endDate = max, obligation.amount = rate × новых дней.
- `GET /api/rentals/active` — список активных позиций (байк, клиент, даты, ставка) для страницы возврата.
- `GET /api/rentals/items/:id/settlement` — деньги по позиции: открытые обязанности (rent/damage, остаток), held-залог (остаток), паспорт (custody), статусы.
- `GET /api/people/search?q=` — поиск клиента по имени/телефону (выдача: имя + телефон).
- `GET /api/dashboard` — очередь `returns` получает clientName + ссылку на /return?item=…; новая очередь `activeRentals` («Сейчас на байках»).

Деньги на возврате переиспользуют существующие ручки: receipts (+allocations), deposits/:id/apply, deposits/:id/return, documents/:id/return, agreements/:id/close.

## UI

- `/rent` — визард в один столбик: Клиент (поиск/новый) → Байк (сетка свободных + скан QR) → Срок (1/2/3/7 или своё) → Залог (кэш/паспорт) → Фото → **ВЫДАТЬ**. Успех: ссылки на договор и клиента + «ещё одна».
- `/return` — выбрать аренду (скан вынесен на общий экран позже; список + ?item=) → карточка: детали, Продлить +1/+3, Возврат (одометр/фото/ущерб) → расчет: К оплате, [Оплачено наличными] / [Вычесть из залога], [Вернуть залог] / [Отдать паспорт] → [Закрыть аренду].
- Дашборд: блок «Сейчас на байках», в «Возвратах» — клиент и метка дней (через N дней / сегодня / N дней просрочено), крупные кнопки «Выдать байк» и «Вернуть байк».

## Вне рамок

RBAC, фоновые задачи, тарифные сетки, изменения существующих страниц (остаются как есть).

## Критерии приемки

- typecheck 0.
- e2e API: quick → settlement → receipt/apply → deposit return/паспорт → close → дашборд содержит возврат и activeRental; extend пересчитывает сумму; негативные кейсы (занятый байк 409, чужой scope 404, QR не из списка).
- Браузер: проходимый визард на dev, возврат с деньгами на dev, проверки на превью.
