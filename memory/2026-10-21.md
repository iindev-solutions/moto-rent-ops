staff-маршрутов (`/login`, `/dashboard`, `/bikes`, `/rent`, `/rentals`, `/return`, `/finance`,
`/documents`, `/maintenance`, `/incidents`, `/people`, `/people/**`, `/agreements/**`, `/b/**`).

остались SPA-шеллом. `npm run typecheck`, `npm run build`, `npm test` — зелёные.
