## SSR лендинга (исправлено)

Изначально глобальный `ssr: false` → HTML-шелл пустой, контент только на клиенте. Для SEO и
og-превью это плохо. Решение: `ssr: true` глобально + `routeRules` с `ssr: false` для всех
staff-маршрутов (`/login`, `/dashboard`, `/bikes`, `/rent`, `/rentals`, `/return`, `/finance`,
`/documents`, `/maintenance`, `/incidents`, `/people`, `/people/**`, `/agreements/**`, `/b/**`).
Проверено: `/` отдаёт 24 КБ HTML с цитатами, `<title>`, `og:*`, canonical; staff-маршруты
остались SPA-шеллом. `npm run typecheck`, `npm run build`, `npm test` — зелёные.

## Светлая тема по умолчанию (21.10)

- Жалоба: «UI всё равно тёмная тема, ничего не понятно». Причина: `preference: system` +
  тёмная ОС → тёмная тема; мелкий шрифт и блёклый muted добивали читаемость

- `app/plugins/default-light.client.ts`: если preference === 'system', принудительно light
- `main.css`: muted темнее в light (#5f6672) и светлее в dark (#b7bdc9); крупнее nav

- theme-color/manifest background: #10100f → #f6f7f9
- Проверка: HTML отдаёт `getStorageValue("localStorage","moto-color-mode")` и preference
  light; SSR `<html>` без класса dark; typecheck 0; 16 тестов passed
