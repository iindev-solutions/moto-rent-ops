## SSR лендинга (исправлено)

Изначально глобальный `ssr: false` → HTML-шелл пустой, контент только на клиенте. Для SEO и
og-превью это плохо. Решение: `ssr: true` глобально + `routeRules` с `ssr: false` для всех
staff-маршрутов (`/login`, `/dashboard`, `/bikes`, `/rent`, `/rentals`, `/return`, `/finance`,
`/documents`, `/maintenance`, `/incidents`, `/people`, `/people/**`, `/agreements/**`, `/b/**`).
Проверено: `/` отдаёт 24 КБ HTML с цитатами, `<title>`, `og:*`, canonical; staff-маршруты
остались SPA-шеллом. `npm run typecheck`, `npm run build`, `npm test` — зелёные.
